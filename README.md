# AWS SAA試験対策動画

- セクション2
  - 4つのステップ
    - 多要素認証 (MFA)
      - スマホのAuth...などのAppを使ってた段階認証を行う
    - 管理者用のIAMユーザーを作成
      - IAMユーザーを作成する理由は rootユーザーでアクセスばかりするとセキュリティ事故が起きた時など、大変だから。
      - 管理者権限ユーザー(root)以外のユーザーを作成し、権限分けや使用者の権限を分けるようにする
        - ※補足 Groupを設定してそこに権限を付与すると便利。理由: いちいち、ユーザーごとに権限を付与しなくて済むから。
    - AWS cloudTrailを有効化する
      - 主要機能
        - オペレーションとAPIのトラッキング
          - ルートアカウント.IAMユーザーの操作を記録
            - S3に保存される
      - 仕様と料金
        - 90日間にイベント状況の保持できる
          - より長期の場合はS3に保存
        - 利用料金
          - CloudTrailの管理イベントの記録及び90日間のイベント履歴の保持/参照は無料
    - AWSの請求アラートを有効化する
      - 請求ダッシュボードで請求アラート設定を有効化する
      - cloudWatchでアラートを設定する
      - 請求アラートの設定
